🏏 IPL Data Analysis Using Python Pandas

📌 Project Overview

This project performs IPL (Indian Premier League) data analysis using Python and Pandas.

The main objective of this project is to analyze IPL match data and find useful information about batsmen, bowlers, teams, seasons, and match winners.

If the "IPL.csv" dataset is not available, the program automatically generates simulated IPL data for analysis.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Jupyter Notebook / Google Colab

📂 Dataset Information

The project uses an IPL dataset named "IPL.csv".

If the CSV file is missing, mock IPL data is generated automatically using NumPy.

📊 Analysis Performed

The following analysis is performed in this project:

1. Dataset Information – Displays the total number of rows and columns.
2. Top 10 Run Scorers – Finds the batsmen who scored the highest runs.
3. Top 10 Wicket Takers – Finds the bowlers who took the most wickets.
4. Team Performance – Calculates the total runs scored by each team.
5. Matches Per Season – Counts the total matches played in each season.
6. Most Successful Teams – Finds teams with the highest number of match wins.
7. Highest Individual Score – Finds the highest individual scores in a match.

💻 Python Libraries

import pandas as pd

- Pandas: Used for data analysis and manipulation.
- NumPy: Used for generating simulated data and numerical operations.
